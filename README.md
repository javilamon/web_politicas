# Web Políticas - Plataforma de Políticas para Videos

Una aplicación web simple y elegante para mostrar políticas, términos de servicio y condiciones de uso para plataformas de videos.

## Características

- 📄 **Términos de Servicio** - Condiciones completas para el uso de la plataforma
- 🔒 **Política de Privacidad** - Información sobre recopilación y uso de datos
- 📹 **Normas de Uso** - Directrices para la subida y gestión de contenido de video
- ⚖️ **Derechos de Autor** - Información sobre propiedad intelectual y DMCA

## Tecnologías

- HTML5
- CSS3 (con diseño responsivo)
- JavaScript Vanilla (sin dependencias)

## Estructura del Proyecto

```
web_politicas/
├── index.html      # Página principal con todo el contenido
├── styles.css      # Estilos y diseño responsivo
├── script.js       # Funcionalidad de navegación
└── README.md       # Este archivo
```

## Uso

1. **Visualización Local**
   - Abre el archivo `index.html` en tu navegador web
   - No se requiere servidor web ni instalación

2. **Navegación**
   - Usa el menú de navegación para cambiar entre secciones
   - Las URLs incluyen hash (#) para compartir secciones específicas
   - Funciona en navegadores modernos y dispositivos móviles

3. **Atajos de Teclado**
   - `Alt + 1`: Términos de Servicio
   - `Alt + 2`: Política de Privacidad
   - `Alt + 3`: Normas de Uso
   - `Alt + 4`: Derechos de Autor

## Despliegue

Para desplegar esta aplicación:

1. **GitHub Pages**
   - Sube los archivos a un repositorio de GitHub
   - Activa GitHub Pages en la configuración del repositorio
   - La página estará disponible en `https://usuario.github.io/repositorio`

2. **Servidor Web**
   - Copia todos los archivos a tu servidor web
   - Asegúrate de que `index.html` sea el archivo de inicio

3. **Netlify/Vercel**
   - Conecta tu repositorio
   - El despliegue es automático

## Personalización

Para adaptar las políticas a tu plataforma:

1. Edita el contenido en `index.html`
2. Ajusta los colores en `styles.css` (busca `#667eea` y `#764ba2`)
3. Modifica el logo o título en el header
